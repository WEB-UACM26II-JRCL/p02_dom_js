# Práctica 02: Manipulación del DOM

## Objetivo

Consultar y modificar elementos HTML mediante JavaScript con `getElementById()` y `getElementsByClassName()`.

## Archivos

- `index.html`: estructura completa de la página.
- `style.css`: diseño visual y clase `.destacada`.
- `app.js`: funciones que debe completar el estudiante.

## Ejecución

Abrir `index.html` en un navegador. Abrir las herramientas de desarrollo (F12) para revisar la consola.

## Actividades

1. Leer y escribir contenido con `getElementById()`.
2. Acceder a las tarjetas con `getElementsByClassName()`.
3. Recorrer una colección con `for`.
4. Aplicar y quitar la clase CSS `destacada`.
